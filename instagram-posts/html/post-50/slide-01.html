O que é código?

Em português
Se o pedido passar de R$ 200, o frete é grátis. Se não, o frete custa R$ 15.
Em código
if (pedido.total > 200) { frete = 0 } else { frete = 15 }

Código é uma regra do seu negócio escrita para o computador seguir sempre igual, sem interpretar.
