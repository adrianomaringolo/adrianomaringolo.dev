# Roteiros para ChatGPT — posts de humor (post-19 a post-22)

> Cada bloco "Prompt" é autocontido: copie e cole direto no ChatGPT, um post por conversa (ou um por mensagem).
> O texto entre aspas é o texto **exato** que deve aparecer na imagem.

**Dica:** se o ChatGPT errar acentos ou trocar palavras, peça "gere a mesma imagem sem nenhum texto, deixando os espaços dos cards vazios" e aplique o texto por cima no Canva/Figma com a fonte Manrope.

## post-19 — Se o Git fosse um relacionamento

**Conceito:** um casal de personagens (dois "commits" fofos, ou duas pessoas estilizadas) vivendo as fases do relacionamento, cada fase associada a um comando do Git.

**Estrutura:**
1. Topo: pill "Humor de dev" + título grande
2. Grid 2×2 com 4 cards, cada um com mini-ilustração + termo + frase
   - Commit → personagem mandando mensagem no celular, sorrindo sem graça
   - Branch → dois personagens seguindo por galhos diferentes de uma árvore/bifurcação
   - Merge conflict → casal discutindo, balões de fala com `<<<<<<<` e `>>>>>>>`
   - Force push → personagem empurrando uma pilha de papéis (o "histórico") para dentro de um buraco, assobiando
3. Rodapé: faixa em destaque com a frase final + @
